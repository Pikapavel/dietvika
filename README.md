# DietVika — первая тестовая версия

PWA-трекер порций методом рук для клиентов диетолога. Клиент отмечает порции групп (фрукты, овощи, зерновые, белок, молочные), воду и свободный приём пищи. Калории клиенту не показываются. Все данные хранятся только на телефоне клиента (localStorage), сервера нет.

## Как запустить

Нужен Node.js 20+.

```bash
npm install
npm run dev            # разработка: http://localhost:5173
npm run build          # проверка типов + сборка PWA в dist/ (манифест, service worker, офлайн)
npm run preview        # посмотреть собранный dist/ локально
npm run build:single   # один HTML-файл для превью: dist-single/index.html (без service worker)
```

`dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify и т. п.), пути относительные. Service worker работает только по https или на localhost.

## Где лежат данные

| Файл | Что это |
|---|---|
| `src/data/plans-usda-2020.json` | 12 планов USDA (1000–3200 ккал): дневные цели по группам. Копия `data/plans-usda-2020.json` проекта. |
| `src/data/справочник-продуктов.csv` | Справочник продуктов (исходник). |
| `src/data/foods.json` | Продукты для шторок групп. **Генерируется** из CSV: `npm run foods`. Пропускаются строки с порцией «?», группа «Масла (Советы)» и «Сметана, сливки…». Творог — в молочных: 3 столовые ложки с горкой ≈ 100 г = 1 порция. |
| `scripts/csv-to-foods.mjs` | Конвертер CSV → foods.json. |
| `scripts/make-icons.mjs` | Рисует иконки в `public/` (`npm run icons`). |

Код, который стоит знать:

- `src/units.ts` — всё про единицы и подписи порций (меры руками, «Что доесть», склонения, совет про сахар). Журнал хранится в единицах USDA (cup / oz-eq). Счёт — USDA (ладонь мяса = 3 порции белка), так решила Вика 15.10: у британской модели нет уровней калорийности. Константа `ACTIVE_SYSTEM` остаётся `"usda"`.
- `src/plan.ts` — план, цели, вода, кодирование ссылки.
- `src/nasem.ts` — калькулятор для специалиста (NASEM 2023, BMR Mifflin–St Jeor, правило −500). Коэффициенты нужно сверить с письмом Вики «Формулы BMR и таблица PAL».
- `src/stats.ts` — итоги недели и текст сводки для специалиста.

### Ключи localStorage

Все с префиксом `dv2-`:

- `dv2-plan` — план клиента;
- `dv2-log` — отметки по датам: `{"2026-10-15": [{"g":"prot","f":"Курица","q":3,"t":1760000000000}]}`. `g` — группа (`fruit`, `veg`, `grain`, `prot`, `dairy`, `water`, `free`), `f` — продукт, `q` — количество в cup / oz-eq (вода — стаканы, свободный приём — 1), `t` — время отметки;
- `dv2-weight` — вес по датам: `{"2026-10-15": 68.4}`;
- `dv2-onboarded` — онбординг пройден;
- `dv2-theme` — тема (как в системе / светлая / тёмная).

Если хранилище недоступно (приватный режим), приложение работает, но данные живут только до перезагрузки.

## Как работает ссылка-приглашение

1. Специалист открывает `…/#/vika` (без входа, только для теста), вводит данные клиента: пол, возраст 19+, рост, вес, активность, цель.
2. Приложение считает расход по NASEM 2023, BMR и предлагает уровень плана. Для снижения веса: расход − 500, не ниже BMR и не ниже 1600, округление вниз до уровня таблицы (шаг 200). Для поддержания — до ближайшего уровня. Галочка «Вегетарианец (белок ×1,5)» поднимает цель белка. Уровень, цели по группам и воду можно поправить.
3. «Собрать ссылку» даёт адрес вида `https://…/#plan=<base64url(JSON)>`, где JSON:
   ```json
   {"v":1,"client":"Анна","specialist":"Вика","kcal":1800,"start":"2026-10-15",
    "goals":{"veg":3},"water":10,"veg":true}
   ```
   `goals`, `water` и `veg` необязательны: без них берутся таблица USDA и 8 стаканов. `"veg": true` — вегетарианский план: белок ×1,5 к цели таблицы (округление до 0,5; например, 1800: 5 → 7,5), мясо и рыба скрыты из списка продуктов, вегетарианские источники белка — первыми. Число белка из `goals` важнее. Поле `freeLimit` из старых ссылок игнорируется: у свободного приёма пищи лимита нет.
4. Клиент открывает ссылку → экран «Вика назначила тебе план…» → «Принять план». План сохраняется в `dv2-plan`, хэш из адреса убирается. Новая ссылка заменяет план, отметки и вес остаются.

Без сохранённого плана показывается приветствие с кнопкой «Посмотреть демо» (план 1800).

Ссылка ничем не подписана: в тестовой версии клиент технически может поменять план сам. Для реальной работы нужна проверка подписи или сервер.

## Экраны

- **Онбординг** (4 слайда, можно пропустить, открывается снова из «Порций»): порция руками, тарелка, пример дня, как отмечать.
- **Сегодня**: кольца 5 групп, плитки с − / +, вода, свободный приём пищи (счётчик за выбранный день, без цели и лимита: «мой подход не в ограничении» — Вика), строка про добавленный сахар с кнопкой «!» → лист «Сахар», шторка группы с подсказками, выбором количества, продуктами и списком отметок, подсказка «Что доесть», переключатель «Вчера / Сегодня».
- **Неделя**: столбцы по дням, средние по группам, дни со всеми кольцами, серия, свободные приёмы пищи по дням и за неделю, вода, вес.
- **Порции**: теория по группам, советы (сахар — с листом «Сахар», соль, масло, орехи, вода), тарелка, пример дня.
- **План**: цели, специалист, «Отправить сводку» (share или копирование), тема, сброс данных.
